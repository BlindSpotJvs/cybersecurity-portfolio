# Cybersecurity Portfolio

**Network Security | Threat Analysis | Offensive Security**

This repository documents hands-on cybersecurity investigations, security research, and technical laboratory projects focused on network analysis, threat detection, vulnerability identification, and defensive security operations.

The objective is to demonstrate structured investigative methodologies, practical security tooling, and evidence-based technical analysis.
